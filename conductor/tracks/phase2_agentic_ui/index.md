# Track: Agentic UI Foundation (Phase 2)

**Goal:** Implement the "Agentic Operating System" frontend—a Map-First, 3-panel interface driven by the synthetic data plan.

**Context:**
We have finalized the [UI Specification](../../docs/UI/UI_SPECIFICATION.md) and [Agentic Patterns](../../docs/concepts/agentic_ui_patterns.md). This track focuses on building the *frontend reality* of those documents.

**Strategy: "Data-First, Mock-Driven"**
Instead of waiting for complex backend ML, we will first implement the `SYNTHETIC_DATA_PLAN.md`. We will build the UI to render a "Perfect Day in the Life" scenario from hardcoded JSON. This ensures the UX is validated before backend integration.

- [Spec](spec.md) - Points to the official UI Specs.
- [Plan](plan.md) - The step-by-step execution guide for Claude.
- [Reference](../../docs/UI/UI_SPECIFICATION.md) - The visual bible.
- [Data Plan](../../docs/UI/SYNTHETIC_DATA_PLAN.md) - The logic source.
