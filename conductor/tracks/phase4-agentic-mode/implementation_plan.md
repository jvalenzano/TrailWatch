## Overview

Phase 4 implements the Agentic Mode UI, featuring a map-first layout with spatial insights. This mode provides full AI capabilities for power users who want to leverage AI-generated insights for efficient trail maintenance triage.

### Key Differentiators from Moderate Mode

| Feature | Moderate | Agentic |
|---------|----------|---------|
| Layout | List-first (sidebar + map) | Map-first (25/50/25 columns) |
| Spatial Insights | Hidden | Visible sidebar |
| Marker Clustering | Individual markers | Clustered with counts |
| Batch Operations | Disabled | Enabled (future) |
| Streaming Extraction | Disabled | Enabled (future) |

## Component Architecture

### Layout Hierarchy

```
Dashboard.tsx
├── AppShell
│   └── MapFirstLayout (NEW - when mode.features.mapPrimary === true)
│       ├── SpatialInsightsSidebar (NEW - 25% width, left)
│       │   ├── InsightCard (repeating)
│       │   └── EmptyInsightsState
│       ├── MapView (existing - 50% width, center)
│       │   └── MarkerCluster (NEW)
│       └── ReportList (existing - 25% width, right)
│           └── ReportCard
└── ReportDetail (slides up from bottom, existing)
```

### Conditional Layout Selection

```tsx
// In Dashboard.tsx
const { mode } = useUIMode();

return (
  <AppShell>
    {mode.features.mapPrimary ? (
      <MapFirstLayout>
        <SpatialInsightsSidebar />
        <MapView />
        <ReportList />
      </MapFirstLayout>
    ) : (
      <ListFirstLayout>
        {/* existing traditional/moderate layout */}
      </ListFirstLayout>
    )}
  </AppShell>
);
```

## New Components

### 1. MapFirstLayout

**File:** `src/components/layout/MapFirstLayout.tsx`

**Purpose:** Three-column responsive layout for agentic mode

**Props Interface:**
```typescript
interface MapFirstLayoutProps {
  children: React.ReactNode;
}
```

**Layout Specification:**
- Desktop (≥1280px): 25% / 50% / 25%
- Tablet (≥768px): 30% / 70% / hidden (reports panel collapses)
- Mobile (<768px): Stack vertically (map first, then insights, then list)

**Styling:**
```css
/* Tailwind classes */
.map-first-layout {
  @apply grid grid-cols-1 md:grid-cols-[30%_70%] xl:grid-cols-[25%_50%_25%] h-full;
}
```

---

### 2. SpatialInsightsSidebar

**File:** `src/components/map/SpatialInsightsSidebar.tsx`

**Purpose:** Display top spatial insights generated by AI

**Props Interface:**
```typescript
interface SpatialInsightsSidebarProps {
  insights: SpatialInsight[];
  onInsightClick: (insight: SpatialInsight) => void;
  selectedInsightId?: string;
  isLoading?: boolean;
}
```

**Behavior:**
- Displays top 3-5 insights
- Clicking an insight:
  1. Zooms map to insight's bounding box
  2. Highlights related reports on map
  3. Filters report list to show related reports

---

### 3. InsightCard

**File:** `src/components/map/InsightCard.tsx`

**Purpose:** Individual insight display with summary and action

**Props Interface:**
```typescript
interface InsightCardProps {
  insight: SpatialInsight;
  onClick: () => void;
  isSelected?: boolean;
}
```

**Visual Elements:**
- Icon based on insight type (cluster, pattern, anomaly)
- Title (e.g., "3 erosion reports near Eagle Creek")
- Summary (2-3 lines)
- Report count badge
- Confidence indicator (reuse from Phase 3)

---

### 4. MarkerCluster

**File:** `src/components/map/MarkerCluster.tsx`

**Purpose:** Cluster nearby markers for performance and clarity

**Props Interface:**
```typescript
interface MarkerClusterProps {
  reports: Report[];
  onClusterClick: (reportIds: string[]) => void;
  highlightedReportIds?: string[];
}
```

**Implementation Notes:**
- Use MapLibre's built-in clustering or `supercluster` library
- Cluster radius: 50px at zoom 10
- Show count in cluster marker
- Expand cluster on click (zoom in or show popup)

## Type Definitions

### SpatialInsight (already defined in src/types/spatial.ts)

```typescript
interface SpatialInsight {
  id: string;
  type: 'cluster' | 'pattern' | 'anomaly';
  title: string;
  summary: string;
  confidence: number; // 0-1
  boundingBox: BoundingBox;
  reportIds: string[];
  createdAt: string;
}

interface BoundingBox {
  north: number;
  south: number;
  east: number;
  west: number;
}
```

## Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| MapLibre clustering complexity | Use `supercluster` library for client-side clustering |
| Responsive layout challenges | Start with desktop, iterate on mobile |
| Performance with many markers | Clustering reduces DOM nodes |
| Mock data mismatch with future API | Define clear interfaces, document assumptions |
